Simple Rules

4 Rules for Variable Names

RULE #1

No Numbers First

Cannot start with a digit (0-9).

1st_place ❌
place_1 ✅
RULE #2

No Spaces

Use underscore _ instead!

my score ❌
my_score ✅
RULE #3

No Symbols

No @ # $ % ! allowed.

coins$ ❌
coins ✅
RULE #4

No Python Words

Cannot use commands like print!

print ❌
my_print ✅
💡 Snake Case vs Camel Case: In Python we connect words using underscores like my_score (snake_case 🐍). In some other languages programmers write myScore with a capital letter (camelCase 🐪)!
